# HELIOS System Icons

This folder contains protected HELIOS design-system icon assets.

Rules:

- Render these image assets directly.
- Do not recreate protected icons with SVG paths, icon libraries, or custom vector approximations.
- Preserve canonical geometry, proportions, stroke treatment, glow, and optical balance.
- Add future approved icons here before wiring them into navigation, shortcuts, widgets, or settings.
