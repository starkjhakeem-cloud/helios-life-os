# HELIOS V2 — Feature Matrix

**Version:** V2 Final Completion Pass  
**Date:** 2026-06-12  
**Branch:** helios-v2

This matrix is the authoritative reference for what is real, what is simulated, and what is stubbed in V2. It exists so that demos, docs, and future engineers never overstate the system's capabilities.

---

## Legend

| Symbol | Meaning |
|--------|---------|
| ✅ REAL | Fully implemented; uses real infrastructure (PostgreSQL, JWT, etc.) |
| 🟡 MOCK | Returns deterministic fake data; no external calls made |
| 🔵 STUB | Architecture wired end-to-end; real path blocked by a flag; harmless placeholder returned |
| ⚙️ CONFIGURABLE | Real when env vars are set; mock/stub otherwise |

## What Is NOT in V2

| Item | Reason |
|------|--------|
| Real Google API calls | `_STUB=True` on both adapters; no credentials required |
| Real Gmail reading or sending | Stub only; no email sending in V2 |
| Real-time calendar sync | Sync is mock; deterministic fixture data |
| Push token registration | Local notifications only; no APNs/FCM server push |
| Multi-user collaboration | All data is user-scoped; no sharing |
| Token refresh (OAuth) | Not implemented; required before real OAuth activation |
| PKCE (OAuth) | Architecture note in checklist; not implemented |
| Vector memory search | Flat DB lookup only; no embeddings |
